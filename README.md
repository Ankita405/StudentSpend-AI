
# StudentSpend AI

### Spend Smarter. Live Greener.

StudentSpend AI is an AI-powered student financial management platform designed to help college students manage their expenses, allowances, budgets and savings while encouraging responsible and sustainable consumption.

## Sustainable Development Goals

- SDG 12 – Responsible Consumption and Production
- SDG 11 – Sustainable Cities and Communities
- SDG 13 – Climate Action

## Technology Stack

### Frontend

- JavaScript
- Recharts

### Backend
- Python
- FastAPI

### Database
- PostgreSQL
- SQLAlchemy

### AI and Machine Learning
- Pandas
- NumPy
- Scikit-learn

### Version Control
- Git
- GitHub

## Main Features

1. User Registration and Login
2. Expense Management
3. Budget Management
4. Savings Goals
5. Financial Dashboard
6. AI Expense Categorization
7. Spending Pattern Analysis
8. Expense Prediction
9. Unusual Spending Detection
10. Sustainability Recommendations
11. Environmental Impact Estimation
12. AI Financial Assistant
